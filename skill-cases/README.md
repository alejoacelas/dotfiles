# Skill cases

Saved examples from which to develop and evaluate skills. Capture a case with
[$save-skill-case](../skills/save-skill-case/SKILL.md).

Each case lives in `<short-name>/case.md`, with its evidence, draft skill and
trial results alongside it. Add the idea, current status and case link below so
future sessions can find and resume it.

This repository is public. Private evidence and wholly private cases belong in
`~/best/dotfiles/private-skills/skill-cases/`; keep only safe pointers here.
