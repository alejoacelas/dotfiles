# Technical operator

IT, operations or data-privacy staff who run infrastructure and accounts for an organisation of roughly 10–100 people.

## Knows

- Cloud consoles (DigitalOcean, AWS, Google Cloud) and how to create servers, volumes, firewalls and billing accounts.
- Linux basics: SSH keys, `sudo`, users and groups, systemd, package updates.
- Admin consoles for Google Workspace, Microsoft 365 or Slack, including app approval and API controls.
- Password managers, sharing secrets with one person, and rotating credentials.
- Privacy concepts: encryption at rest, data processing agreements, retention, least privilege.

## Explain

- How AI coding agents work: what Claude Code, Codex and Cowork do, where they run, and what data reaches the model provider.
- Agent permission modes, and what the agent can do on its own.
- Anything specific to the project: why each decision was made, and what it trades off.

## Looks for first

What they must decide or approve, what it costs, where the data goes, who can read it, and how much ongoing work it creates.
