# Twitter tools

My tools for Twitter live here. Each one stays in its own repo.

- [No Numbers for X](https://github.com/alejoacelas/no-numbers-for-x) hides engagement counts without disabling the buttons.
- [X follow graph](https://github.com/alejoacelas/x-follow-graph) maps the accounts I follow, their communities, and weak ties.
- [x-list-sync](https://github.com/alejoacelas/x-list-sync) finishes selected private Lists within a fixed API budget.
