# Services

Repositories for clients, grouped by the company that hires Alejo:
`services/<company>/YYYY-MM-project-name/`. Each project is its own private
repository, so a deliverable can be shared with one client without exposing others.
Finished projects move to `~/best/archive/`; record the move in its README.

A project gets a repository here when it has code that runs or gets deployed, or
when the client receives the repository itself. Documents, research and prep go in
`~/best/desk/` instead. Register each repository there with a pointer item, following
`~/best/desk/AGENTS.md`; to find the people involved, search desk for the
repository's path.

Each company folder has an `AGENTS.md`. Before working on a project, read the
company's `AGENTS.md`, the project's `AGENTS.md` and the latest calls with the
people involved (desk items whose `projects:` names the company). Link to calls;
never copy transcripts into a project.

Record in the project's `AGENTS.md` the Google account it uses and anything still
running or billing.
