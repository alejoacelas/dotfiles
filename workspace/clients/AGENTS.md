# Clients

Projects for clients, grouped by the company that hires Alejo:
`clients/<company>/YYYY-MM-project-name/`. Each project is its own private
repository, so a deliverable can be shared with one client without exposing others.

Each company folder has an `AGENTS.md` and, once calls exist, a `calls` symlink to
`~/best/calls/clients/<company>/`, created by the summarize-call skill. Before
working on a project, read the company's `AGENTS.md`, the project's `AGENTS.md`
and the latest calls with the people involved. Link to calls; never copy
transcripts into a project.

Record in the project's `AGENTS.md` the Google account it uses, what was
delivered and when, and anything still running or billing.
