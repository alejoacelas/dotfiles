# Clients

Repositories for clients, grouped by the company that hires Alejo:
`clients/<company>/YYYY-MM-project-name/`. Each project is its own private
repository, so a deliverable can be shared with one client without exposing others.
Finished projects move to `clients/<company>/archive/`.

A project gets a repository here when it has code that runs or gets deployed, or
when the client receives the repository itself. Documents, research and prep go in
the person's folder in `~/best/desk/` instead. Register each repository there,
following `~/best/desk/AGENTS.md`.

Each company folder has an `AGENTS.md` and a `desk` symlink to the
company's folder in `~/best/desk/`, created by the summarize-call skill. Before
working on a project, read the company's `AGENTS.md`, the project's `AGENTS.md`
and the latest calls with the people involved. Link to calls; never copy
transcripts into a project.

Record in the project's `AGENTS.md` the Google account it uses and anything still
running or billing.
