# projects

Create dated one-off projects as `YYYY-MM-project-name`. Every one-off must have its own
Git repository and GitHub remote. Declare the `once` shared-context group (the group ID is unchanged) in its AGENTS.md using
`agent-context adopt`, state its scope briefly, and make CLAUDE.md contain `@AGENTS.md`.
Apply the global privacy rules. Move finished projects to `~/best/archive/`.
