# best

An ordinary folder of independent repositories. Start new work with `proj`
(see the `today` skill) and read the destination's `AGENTS.md` first.

- `inbox/`: work whose home isn't clear yet.
- `clients/<company>/`: projects for clients, grouped by the company that hires Alejo.
- `projects/`: Alejo's own projects. New ones sit at the top; topic folders hold the
  rest, and `in-use/` holds the ones he relies on.
- `trials/`: structured tool trials, one public repository.
- `strategy/`: planning for the AI-uplift practice.
- `calls/`, `writing/`, `me/`: call archive, writing and reference, personal material.
- `archive/`: retired work. Project groups also keep their own `archive/`.

Keep shared instructions and container configuration in dotfiles.
