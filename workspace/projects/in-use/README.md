# In use

Tools I built or adapted and now rely on. Fix them when they break; develop them
further only with a concrete next test.

- `cmd-tab/` — the Command-Tab app; runs as a login item from `.build/CmdTab.app`.
- `credentials/` — narrowing what agents can reach; secret scanning still to add.
- `dictation/` — the FluidVoice setup and Murmur replacement.
- `fetch-url/` — URL retrieval CLI.
- `gdoc/` — Google Docs CLI fork and MCP wrapper; the hosted connector still needs production OAuth.
- `gws/` — Google Workspace CLI and bounded Drive access.
- `model-router-check/` — daily launchd check that GPT routing and the 1M Claude window still work.
- `my-vm/` — VM provisioning; `~/.local/bin/my-vm` links here.
- `roughdraft/` — the Markdown review app.
- `search-bar/` — works; connected-source search unfinished.
- `shortcuts/` — the shortcut system, from a conservative base.
- `sleep/` — agent-aware sleep daemon.
- `spotlight/` — the Launcher app.
- `twitter/` — the extension, follow-graph and list tools.
- `video-blur/` — recording redaction and private experiment reports; recordings stay in calls.
