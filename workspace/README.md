# best

My workspace. This folder is not a Git repository; projects and note collections
own their repositories.

- `inbox/` — where I start sessions for loose work, plus anything not yet filed.
- `clients/` — client repositories, one folder per company, linked to its people in `desk/`.
- `projects/` — my own projects; undated folders are the ones I use regularly,
  including tool trials and writing.
- `strategy/` — planning for the AI-uplift practice.
- `desk/` — one folder per person: call transcripts and summaries, plus quick work for them.
- `me/` — personal material, relationships, blog and website.
- `archive/` — retired work not tied to a client or person.
- `dotfiles/` — shared instructions, hooks, skills and machine configuration.

Run `proj <name> --claude` to start a project, and `/today` at the start of a day.
