# Developer peer

Someone who writes software and wants to run, fork or adapt the project.

## Knows

- Git, GitHub, package managers, virtual environments, environment variables and `.env` files.
- Reading code and tests to find out how something works.
- Getting API keys from common providers, and that free tiers and quotas exist.
- Their own operating system and terminal.

## Explain

- Which accounts and keys the project needs, where to get each one, and what it costs.
- Any step that depends on hardware, a platform or a paid service.
- Choices that look odd without context, briefly.

## Looks for first

What the project does, a working example, and the shortest path to running it.
